# Icon 網格規範 v0.1

這份規範的目的只有一個：讓不同時間、不同人畫出來的 icon 放在一起時看起來像同一套。每條規則都可以被 `npm run lint:icons` 或預覽頁檢查到，不靠記憶。

## 三種 icon

| 類型 | ���在哪裡 | 顏色 | 會輸出成 |
| --- | --- | --- | --- |
| UI icon | `icons/ui/` | 單色，build 時自動改成 `currentColor` | SVG、sprite、React 元件、icon font |
| 符號 | `icons/symbols/<類別>/` | 同 UI icon | 同 UI icon |
| 品牌符號 | `icons/brand/` | 可多色、可漸層、可用線條 | SVG、sprite、React 元件（不進 icon font） |

判斷方式：會出現在按鈕、選單、表單裡，需要跟著文字變色的，是 UI icon。代表某個專案或產品本身的，是品牌符號。表達一個概念而非介面動作的，是符號。

### 符號分類

符號依**內容**分類存放，類別即 `icons/symbols/` 下的子目錄：

| 類別 | 收什麼 |
| --- | --- |
| `math` | 數學：運算子、關係符號、希臘字母（π、Σ、Δ）、微積分符號 |
| `philosophy` | 哲學：陰陽、天平、問號、圓相、沙漏、螺旋等思想概念 |
| `science` | 科學：原子、燒瓶、DNA、分子、軌道、波形、磁鐵等學科意象 |
| `theology` | 神學：人類以感官觀察生存世界、以及親手創作的各種實體物（日月星辰、山川草木、眼與心、書與火） |

要開新類別就加一個 kebab-case 子目錄，build 與預覽頁會自動跟上（預覽頁的類別標題在 `scripts/build-preview.mjs` 的 `CATEGORY_LABELS`）。

## 畫布與安全區

- 畫布固定 **24 × 24**，`viewBox="0 0 24 24"`。
- 四周保留 **2px 留白**，圖形畫在中間 **20 × 20** 的範圍內。只有需要視覺補償的尖角或細部可以超出到留白區。
- 網格模板在 `templates/icon-grid-24.svg`，在 Figma、Illustrator 中放大使用。

## 基準形狀（Keylines）

不同外形的 icon 對齊不同基準，視覺重量才會一致：

| 外形 | 基準尺寸 | 例子 |
| --- | --- | --- |
| 圓形 | 直徑 20 | 搜尋、時鐘、使用者頭像 |
| 正方形 | 18 × 18，圓角 2 | 設定面板、相片、日曆 |
| 直式矩形 | 16 × 20，圓角 2 | 文件、手機 |
| 橫式矩形 | 20 × 16，圓角 2 | 卡片、螢幕、信封 |

圓形看起來比同尺寸的正方形小，所以圓形用 20、正方形用 18，兩者放在一起才會等重。

## 線條

- 設計時統一用 **2px 線寬**。
- 端點與轉角一律 **圓頭（round cap、round join）**。
- 內部圓角半徑 **2**，小細節可用 1。
- 線段之間最小間距 **2px**，小於這個值在 16px 尺寸下會糊在一起。
- 斜線優先用 **45°**，其次 30° / 60°，避免任意角度。
- 座標盡量落在整數或 .5，讓 2px 線條在 1x 螢幕上對齊像素。

## 匯出前必做

1. **外框化線條**（Figma：Outline stroke；Illustrator：Expand / Outline Stroke），再合併成單一形狀。
   原因：icon font 只認填色，未外框化的線條在字型裡會消失或變成空心。
2. 刪掉網格模板的 `guides` 群組。
3. 不要有文字、點陣圖、`<style>`、遮罩或濾鏡。
4. 檔名用 kebab-case 英文：`arrow-right.svg`、`file-plus.svg`。

外框化的代價是之後不能在程式裡調整線寬。這是刻意的取捨：線寬是品牌規則的一部分，不該由各專案自行修改。如果未來真的需要多種線寬，再新增 `icons/ui-light/` 一類的獨立集合。

## 命名

- 格式：`主體-修飾`，例如 `arrow-right`、`file-plus`、`user-check`。
- 用「它是什麼」命名，不用「它在哪裡用」：`trash` 而不是 `delete-button`。
- 同一概念的變體放在後面：`heart`、`heart-filled`。
- 名字一旦發布就不改名，要改就新增一個，舊的標記為廢棄後保留一個版本。

## 使用尺寸

| Token | 尺寸 | 用在 |
| --- | --- | --- |
| `icon.size.sm` | 16px | 行內文字、緊湊表格 |
| `icon.size.md` | 20px | 按鈕、輸入框 |
| `icon.size.lg` | 24px | 導覽列、工具列（原生尺寸，最清楚） |
| `icon.size.xl` | 32px | 空狀態、說明區塊 |

畫完後在預覽頁的 16px 尺寸檢查一次：如果細節糊掉，代表這個 icon 太複雜，應該簡化而不是另做一個小尺寸版本。

## 新增 icon 的流程

1. 用網格模板畫好，依上面的步驟匯出到 `icons/ui/`。
2. `npm run preview`，打開 `dist/preview.html`，按「顯示網格」比對留白與基準形狀，再切深色模式看一次。
3. Lint 通過、預覽沒問題後提交。`icons/codepoints.json` 會自動新增一筆，請一起提交，它保證 icon font 的字碼永遠不變。
